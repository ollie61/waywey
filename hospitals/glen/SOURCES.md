# MUHC Glen dataset sources and audit notes

Initial WayWey Glen package created 2026-10-27.

## Primary official sources

- MUHC / CUSM, "Finding your way around the Glen site" / "S'orienter au site Glen" — current bilingual block, level and room directory.
- MUHC, "How to get to the Glen site" — 1001 boul. Décarie, main entrances and direct Vendôme tunnel access.
- MUHC, "Admitting Office" — current adult and Montreal Children's admitting locations.
- MUHC, "Test centres" — adult Glen Test Centre at D 02.2307.
- MUHC, "Spiritual care" — adult room C 02.0310.4 and pediatric room A 02.0045.
- MUHC, "Food services" — Glen cafeteria on S1 in Block C.
- MUHC, "Commercial venues" — current retail locations.
- MUHC, Cedars Cancer Centre contact page — dedicated Cedars Test Centre at D RC.1306.

## Important conflict resolution

The current English Glen wayfinding directory lists the adult Test Centre as D 02.1178, while the current French directory and the dedicated MUHC Test Centres page list D 02.2307. WayWey uses D 02.2307 because the dedicated current Test Centres page is the more specific source.

The French wayfinding directory lists adult Spiritual Care as C 02.1178, while the current dedicated MUHC Spiritual Care page and current English wayfinding page list C 02.0310.4. WayWey uses C 02.0310.4.

The general Glen wayfinding directory lists pediatric Spiritual Care at A 02.3734, while the current dedicated MUHC Spiritual Care page lists A 02.0045. WayWey uses A 02.0045.

## Routing policy

Routing is intentionally conservative.

- A ↔ B: Montreal Children's Hospital sector.
- C ↔ D: Royal Victoria / Cedars / Montreal Chest Institute sector.
- Cross-sector A/B ↔ C/D public indoor routing is not yet encoded.
- Block E Research Institute routing is not yet encoded.
- Off-site adult ophthalmology (5252 boul. de Maisonneuve Ouest) is identified as off-site rather than routed as a Glen block.

No staff-only or unverified connector is inferred.
