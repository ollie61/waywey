# WayWey

**The Ambassador Magic**

WayWey is an unofficial multilingual wayfinding tool for Jewish General Hospital ambassadors.

## Current prototype
- Ambassador station is set once and remembered on the device
- Search in English or French, including common aliases and room numbers
- Indoor pavilion routing
- Visitor-facing directions in 10 languages
- Large visitor display and device text-to-speech
- Offline caching after the first successful visit

## Important
This is an unofficial prototype and should not be represented as an official Jewish General Hospital application without formal approval. Exact room/location information should be checked against current JGH sources and appointment paperwork when needed.
