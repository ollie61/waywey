# WayWey 1.1.2

Usability update for the isolated 1.1 release target. Production 1.0.0 remains unchanged.

Short search prompts in English, French, Hebrew and Arabic; RTL follows the selected language. Hospital configuration owns ambassador and visitor language choices and defaults. Explicit supported QR languages take priority; remembered languages are scoped to each hospital. Visitor defaults are independent of ambassador choices. Compact language buttons show every configured ambassador language, including HE / EN / AR for Hadassah.

The mint header, guide and location icons are retained. Search and directions use readable spacing, large touch targets and single-column mobile layouts. Sharing controls use the visitor's language. Release details live under Sources and information to reduce header clutter. Floor routing, IDs, room data, geometry and H–K exceptions remain unchanged. Unknown destination floors and K lobby level still need hospital verification; real-device speech still needs Samsung testing.
